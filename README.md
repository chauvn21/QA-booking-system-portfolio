# QA Booking System Portfolio

## Project Overview

Đây là project Manual QA Portfolio cho hệ thống Online Booking System tích hợp các chức năng:

- Authentication & Account Management
- Booking & Checkout
- VNPay Payment
- CTV Referral & Commission
- Wallet & Withdrawal
- Order Management
- CMS Content

Project tập trung vào:
- Testcase Design
- API Testing
- DB Testing
- Integration Testing
- Business Flow Testing
